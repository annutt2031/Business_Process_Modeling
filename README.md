# Business Process Modeling with BPMN

Проект посвящён анализу и моделированию бизнес-процессов информационных систем.

В качестве сквозных предметных областей рассматриваются:

- сервис онлайн-записи в барбершоп;
- система доставки заказов.

Перед построением BPMN-моделей используются ранее подготовленные аналитические артефакты: требования, роли, проблемы пользователей, контекст системы и информационные потоки.

Основные BPMN-модели в репозитории разработаны для сервиса онлайн-записи.

## Предметные области

### Онлайн-запись в барбершоп

Система автоматизирует путь клиента от выбора услуги до получения обратной связи.

Основные участники:
- клиент;
- мастер;
- менеджер;
- система онлайн-записи;
- бухгалтерия;
- внешние сервисы уведомлений.

### Сервис доставки

В качестве второго системного кейса рассматривается служба доставки с оператором, курьером, диспетчером, администратором, поставщиками, клиентами и внешней бухгалтерской системой.

Для этого кейса в репозитории сохранены подготовительные аналитические материалы:
- требования;
- стейкхолдеры;
- роли;
- проблемы;
- контекстная модель;
- DFD;
- глоссарий.

## Подход к моделированию

Перед построением BPMN были выделены бизнес-процессы верхнего уровня.

Для каждого процесса определялись:

- цель;
- результат;
- владелец;
- инициирующее событие;
- входные данные;
- исполнители;
- используемые данные;
- взаимосвязи с другими процессами.

Перед финальной отрисовкой процессы обсуждались командой, а спорные правила фиксировались в отдельных протоколах.

## Основные бизнес-процессы барбершопа

### BP01 — Записать клиента на услугу

Клиент выбирает:
- тип услуги;
- услугу;
- мастера;
- свободный временной слот;
- канал связи.

Система подтверждает доступность времени, создаёт запись и формирует данные для последующих процессов.

### BP02 — Оказать услугу клиенту

Процесс запускается при наступлении времени подтверждённой записи.

В зависимости от ситуации фиксируется:
- успешное оказание услуги;
- неявка клиента.

При успешном результате формируются данные для оплаты и запроса обратной связи.

### BP03 — Принять оплату

После оказания услуги определяется стоимость и способ оплаты.

В модели рассматриваются:
- наличная оплата;
- оплата картой;
- онлайн-оплата.

Факт оплаты регистрируется в системе, клиент получает чек, а данные могут передаваться в бухгалтерию.

### BP04 — Получить обратную связь

После завершения услуги клиенту предлагается оставить оценку и комментарий.

Полученный отзыв сохраняется в системе, после чего менеджер может получить уведомление о новой обратной связи.
